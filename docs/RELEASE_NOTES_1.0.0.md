**One Wigglet for every Claude Code session.** The first public build.

### Install
1. Download `Wigglet.dmg` below and drag **Wigglet** to Applications.
2. First launch (it isn't notarized yet): open it once, click **Done**, then **System Settings → Privacy & Security → Open Anyway**. Or run `xattr -dr com.apple.quarantine /Applications/Wigglet.app`.
3. Open Wigglet, click **Connect**. Sessions you already have open show up straight away.

Requires macOS 13 or later. One universal build runs on Apple silicon and Intel. Later versions install themselves (signed updates from this page only).

### What's in it
- A Wigglet for each session you're working in, in the Claude app, a terminal, VS Code or Cursor. Or one Wigglet for all of them.
- 56 pixel animations tied to real Claude Code activity: reading, typing, searching, testing, building, deploying, waiting on you, and more. Full list in [docs/ANIMATIONS.md](https://github.com/Icore0/wigglet/blob/main/docs/ANIMATIONS.md)
- A live hover card with the latest message and **Jump** back to the session
- Chat with Claude through your Claude Code login, or your own Anthropic, OpenAI, OpenRouter or Gemini key, or a local Ollama model
- No accounts and no analytics

Checksums are in `SHA256SUMS.txt`. Unofficial fan project, not affiliated with Anthropic.
