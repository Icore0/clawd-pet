**One Clawd for every Claude Code session.** The first public build.

### Install
1. Download `ClawdPet.dmg` below and drag **Clawd Pet** to Applications.
2. First launch: right-click the app and choose **Open**. It isn't notarized yet.
3. Click **Connect**, then start a Claude Code session.

Requires macOS 13 or later. One universal build runs on Apple silicon and Intel.

### What's in it
- One Clawd per session, waiting sessions move to the front, and a `+N` badge after six
- 80+ pixel animations tied to real hook events. The full list is in [docs/ANIMATIONS.md](https://github.com/Icore0/clawd-pet/blob/main/docs/ANIMATIONS.md)
- High-five and pass-the-parcel between sessions
- A hover card, plus a chat bar on your own OpenRouter key (stored in the Keychain)
- No accounts and no analytics. Nothing goes over the network unless you chat

Checksums are in `SHA256SUMS.txt`. Unofficial fan project, not affiliated with Anthropic.
