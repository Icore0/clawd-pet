**One Wigglet for every Claude Code session.** The first public build.

### Install
1. Download `Wigglet.dmg` below and drag **Wigglet** to Applications.
2. First launch: right-click the app and choose **Open**. It isn't notarized yet.
3. Open Wigglet and follow the setup screen: **Connect**, then start a Claude Code session.

Requires macOS 13 or later. One universal build runs on Apple silicon and Intel.

### What's in it
- One Wigglet per session, waiting sessions move to the front, and a `+N` badge after six
- 80+ pixel animations tied to real hook events. The full list is in [docs/ANIMATIONS.md](https://github.com/Icore0/wigglet/blob/main/docs/ANIMATIONS.md)
- High-five and pass-the-parcel between sessions
- A full app window: setup with live checks, sessions with Jump, an animation browser and settings
- A live hover card, plus a chat bar on your own OpenRouter key (stored in the Keychain)
- No accounts and no analytics. Nothing goes over the network unless you chat

Checksums are in `SHA256SUMS.txt`. Unofficial fan project, not affiliated with Anthropic.
