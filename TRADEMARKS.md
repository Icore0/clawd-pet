# Credits, trademarks and our promise to Anthropic

## Credits

- **Claude**, **Claude Code** and the pixel mascot that Wigglet is drawn after were made by **Anthropic**. Wigglet is a fan tribute to that mascot. The original character design belongs to Anthropic.
- Wigglet works through Claude Code's public [hooks](https://docs.claude.com/en/docs/claude-code/hooks) feature. Thank you to Anthropic for building Claude Code and for making it this extensible.

## Trademarks

"Claude", "Claude Code" and "Anthropic" are trademarks of Anthropic, PBC. Wigglet uses these names only to say what it works with.

Wigglet is an independent, unofficial fan project. It is **not affiliated with, sponsored by, or endorsed by Anthropic**.

## How we keep it respectful

- Wigglet has its own name. It never calls itself Claude or an Anthropic product.
- No Anthropic logos, wordmarks or brand typefaces are used, in the app, the repo or the website.
- It's free: no ads, no paid tier, no accounts. It collects no data.
- It only uses public, documented Claude Code features. It never touches Anthropic's services on your behalf, except through your own `claude` login when you choose to chat.

## If you're from Anthropic

If you'd like anything changed, renamed or removed (the character design included), please [open an issue](https://github.com/Icore0/wigglet/issues/new) or use **Security → Report a vulnerability** for a private message. We'll respond within 48 hours and comply.
